### Defense in Depth(縱深防禦)：不要相信任何一道防線一定擋得住攻擊(多層防禦)。  

例如一個100萬的現金放在保險箱，小偷需要突破：家門 → 鐵門 → 保險箱 → 密碼鎖 → 監視器 → 警報器等等，很多層，這就是Defense in Depth。  

洋蔥模型(Onion Model)：直向畫，看起來像洋蔥，一層一層。  
Internet → 防火牆(Firewall) → 內部網路(Network) → 主機(Host) → 作業系統(OS) → 應用程式(Application) → 資料(Data)。  
駭客要偷資料要突破每一層。  

生活提款例子：ATM卡 → PIN碼 → 銀行主機驗證 → 提款限額 → 交易紀錄 → 異常偵測。  
就算PIN碼被知道了，沒有ATM卡也沒辦法提款。  

**Defense in Depth需要每一層都防不同東西**，不是一直疊同一個東西就是有用。  
例如：Firewall → Firewall → Firewall → Data。這樣就不是Defense in Depth。  

Defense in Depth包含哪些層？可以大致分為：  
第一層(Physical Security 物理安全)：門禁、監視器、警衛、指紋、機房。  
第二層(Perimeter Security 週邊安全)：VPN、Proxy。  
第三層(Network Security 網路安全)：ACL、IDS、IPS。  
第四層(Host Security 主機安全)：Linux Patch、EDR、Antivirus。  
第五層(Application Security 應用程式安全)：Session、JWT、RBAC、Input Validation  
第六層(Data Security 資料安全)：AES、RSA、Backup、Database Encryption。
