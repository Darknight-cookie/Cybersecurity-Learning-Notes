### Secure by Default(預設安全)：不需要使用者額外設定，系統一開始就是安全的，而不是最方便的設定。  

生活例子：  

Windows以前Administrator都預設啟用，而現在很多版本會限制UAC、預設開啟Windows Defender，開啟BitLocker，這些都是Secure by Default。  

---

Secure by Default與PoLP的關係：  

PoLP指的是「使用者應該有多少權限？」。  
Secure by Default指的是「系統預設應該給多少權限？」。  
**若預設給Administrator就違反了Secure by Default，同時也違反PoLP。**  

---

Security by Design與Secure by Default  
| Security by Design |	Secure by Default |
|--------------------|---------------------|
| 設計理念	| 預設設定 |
| 著重「開發前」 |	著重「安裝後」 |
| 在設計時思考安全	| 出廠就是安全 |
| SDLC相關 |	系統設定相關 |

---

**Security by Design 是「把安全設計進去」，Secure by Default 是「讓安全成為預設」。**
