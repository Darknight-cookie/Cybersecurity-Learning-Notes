### Asset Inventory(資產盤點)：建立完整且持續更新的資產清單，就是公司的「資產戶口名簿」。  
公司需要知道自己有什麼設備，有幾個。  

---

沒有Asset Inventory可能遇到的例子：  

若今天Windows公布有重大漏洞，這時如果不知道「我們公司有幾個Windows」就有可能會有幾台漏掉這種重大更新，所以要做好Asset Inventory。   

---

**資安名言：Unknown Assets become Unmanaged Assets. (不知道的東西就沒人管理。)**  

---

**Asset Inventory盤點什麼？**  

1.	Hardware：Server、Laptop、Mac、Firewall、NAS等。  
2.	Software：Windows、Linux、Office、ERP、CRM等。  
3.	Data：客戶資料庫、原始碼、報告。  
4.	Account：Administrator、Root、Github、VPN。  
5.	Cloud：Azure、GCP、Google Workspace。  
6.	Network：Domain、DNS、VPN。

---

一份完整的Inventory應該長什麼樣？要詳細記事，不是只寫「Linux Server」。  

|櫃位	| 範例	|

| Asset ID	| SVR-001	|

| 類型	| Linux Server |

| 保管人	| 系統管理員 |

| 狀態 |	Running |


---

**Asset Inventory與Asset Management**  

Asset：只是東西，例如ERP Server。  
Asset Inventory：是把全部列出來。  
Asset Management：除了Asset Inventory有的東西之外還會加入：購買、安裝、維護、更新、報廢等等。
