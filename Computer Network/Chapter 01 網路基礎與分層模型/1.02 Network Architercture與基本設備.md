### Network Architercture與基本設備  

---

**最常見的家裡網路**
```text
          Internet
             |
           Router
        /     |     \
       /      |      \
      PC    Phone     TV
```

**裡面包含了好幾種角色**  

PC、Phone、TV都是Host  
Router就是Router  
Wi-Fi → Wireless Access    

**如果公司規模再大一點**  

```text
          Internet
             |
           Router
             |
           Switch
        ┌────┼────┐
        ↓    ↓    ↓
       PC  Server Printer
```
這就是典型的LAN架構  

---

**Host是什麼**  

Host可以理解成「在網路中具有網路身份、可以發送或接收資料的終端裝置」，例如PC、Laptop、Server、Camera等。  

---

**Router算不算Host**  

從廣義的Networking定義來說，Router本身也是一個Network Device，也可能具備Host-like(類似Host)的網路功能。  

---

**Network Device可以分成兩種思考方式**  

- End Devices(終端設備)：PC、Phone、Server。  
- Intermediary Devices(中間設備)：Switch、Router、Access Point。

---

**Switch是什麼**  

Switch是最主要的工作是「在同一個LAN中，根據MAC Address將Ethernet Frame送到適當的Port。  

例如這樣接
 ```text
PC A
 |
 |
 └────────┐
          |
        Switch
        /    \
       /      \
     PC B    PC C
```

**若PC A → PC B**  

Switch需要知道「PC B的MAC Address在哪一個Port？」  

Switch為什麼知道PC B在哪  

利用MAC Address Table，例如  
```Port 1 → AA:AA:AA:AA```  
```Port 2 → BB:BB:BB:BB```  
```Port 3 → CC:CC:CC:CC```  

假設PC A的MAC = AA:AA…，那代表接在Port 1上。  

而PC B的MAC = BB:BB…，那就是接在Port 2上。  

**當A要傳給Frame給B**  

Destination MAC(目標MAC位置) → BB:BB:BB:BB → Swtich MAC Table → Port 2 → PC B。  

---

**Router是什麼**  

Router的核心工作是「連接不同的IP Network，並根據Routing Information決定Packet下一步往哪裡走。」  

例如  
```text
Network A
192.168.1.0/24
       |
       |
     Router
       |
       |
Network B
10.0.0.0/24
```

這兩個是不同的Network，Router就負責在不同Network之間轉送資料。  

---

**Swtich和Router的差異**  

| |	Switch |	Router |
|--|-------|---------|
| 主要Layer | Layer 2 |	Layer 3 |
| 主要看的資訊 |	MAC Address |	IP Address |
| 主要單位 |	Frame |	Packet |
| 主要用途 |	LAN內轉送 |	不同Network間轉送 |
| 核心表格	| MAC Address Table |	Routing Table |

---

**用寄信例子理解**  

Switch像同一棟大樓裡的郵件分發中間，它要知道這封信是給哪一個房間。  

Router比較像不同城市之間的物流中心，它要決定這批貨下一站應該送去哪個城市。  

---

**為什麼家裡的Router看起來又像Switch**  

其實家裡的Wi-Fi Router通常是一台多功能網路設備，可能同時包含  
- Router
- Switch
- Wireless AP
- NAT
- DHCP Server
- Firewall

---

**Access Point(存取點)是什麼**  

Access Point(AP)主要工作是「讓Wireless(無線) Devices能夠連接到有線LAN」。  

例如Laptop → AP → Ethernet → Switch → LAN。  

所以AP可以理解成Wireless與Wired(有線) Network之間的橋樑之一。  

---

**Server是什麼**  

Server是提供服務的角色，不是單純指某種硬體，例如Web Server、DNS Server，一台普通電腦也可以執行Server Software，然後成為Server。  

---

**Client是什麼**  

Client是向Server要求服務的一方  

像是Browser(瀏灠器) → HTTP Request → Web Server。  

這時Browser就是Client，Web Server就是Server。  

---

**Client-Server Model**  

最基本架構  
```text
Client
   │ Request
   ↓
Server
   │ Response
   ↓
Client
```

例如開網站  
```text
Browser
   │ GET /
   ↓
Web Server
   │ HTTP Response
   ↓
Browser
```

---

**Peer-to-Peer(點對點 P2P)**  

並不是所有網路都一定是Client → Server，例如  
```text
PC A ────── PC B
 │            │
 └──────┬─────┘
        │
       PC C
```

每個Peer都可能同時「提供服務 + 使用服務」  

---

**Network Topology(網路拓撲)**  

網路裡的裝置到底怎麼連，常見的模型有  


**Star Topology**  

現在LAN非常常見，如果一條壞掉通常只影響它本身，而且管理也比較方便。  

所有裝置集中連到Central Device，例如Switch。  
```text
        PC
         │
PC ── Switch ── PC
         │
       Server
```
<br><br>

**Bus**  

大家共用同一條傳輸媒介，早期Ethernet曾經使用類似概念。  
```PC ─── PC ─── PC ─── PC```  
<br><br>

**Ring**  

形成環狀  
```text
PC ── PC
│      │
PC ── PC
```
<br><br>

**Mesh(網)**  

節點之間有多條連線。  
```text
A ───── B
│╲     ╱│
│ ╲   ╱ │
│  ╲ ╱  │
│  ╱ ╲  │
│ ╱   ╲ │
C ───── D
```
Mesh優點是Redundancy(冗餘)高，如果一條路徑壞勢，可能還有其他路徑。  

---

**一個需要注意的地方**  

Switch在現實中不是永遠都是Layer 2，選有Layer 3 Swtich，它可以執行部分Layer 3 Routing功能，我們現在記的是典型/基本的角色與功能，並不是絕對的規則。
