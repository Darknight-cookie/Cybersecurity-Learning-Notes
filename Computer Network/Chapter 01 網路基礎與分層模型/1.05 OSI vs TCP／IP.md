**為什麼OSI有七層**  

分成七層的優點是「每一層責任比較清楚」，是一張非常漂亮、清楚的網路功能地圖，它告訴你「這件事屬於哪一類？這個問題在哪一層？這個設備大概在哪一層？」所以OSI很適合  
- 學習網路
- 設計概念
- Troubleshooting
- 描述問題所在的Layer

---

**那TCP/IP為什麼沒有七層**  

Layer只是功能分類，每個Layer都代表是他的功能範圍，而且這樣分更接近現實的Internet。  

---

| | OSI |	TCP/IP |
|---|----|-------|
| 層數 |	7 |	通常4 |
| 分層 |	非常明確 |	比較粗略 |
| 理論性 |	高 |	比較貼近實際 |
| 教學 |	⭐⭐⭐⭐⭐ |	⭐⭐⭐⭐ |
| Troubleshooting |	很好用 |	也常使用 |
| Internet實作 |	不是主要實作架構 |	⭐⭐⭐⭐⭐ |
| Protocol Suite |	否 |	是 |
