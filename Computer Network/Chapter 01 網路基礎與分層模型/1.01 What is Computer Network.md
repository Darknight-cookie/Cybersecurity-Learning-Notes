### What is Computer Network?  

---

**最簡單的定義：Computer Network是讓兩個以上的裝置，透過某種通訊媒介交換資料的系統。**  

其中可以拆成三個重點：「多個裝置 + 通訊媒介 + 資料交換」，例如最簡單的兩台電腦互相傳送資料，這就是一個最基本的Network。  

---

**網路不一定要有「電腦」**  

我們說的Network裝置可以非常多  
- Computer
- Laptop
- Smartphone
- Server
- Printer
- Camera
- Router
- Switch
- IoT Device
  
所以更精確的說：「Network是讓Network Devices/Hosts彼此通訊的系統。」  

例如我們家  

```text
             Router
           /    |    \
          /     |     \
         PC    Phone    TV
```
 
這整個就是一個LAN(區域網路Local Area Network)，指在一個小範圍的地理空間內(例如學校大樓)把電腦、手機、印表機等設備連在一起的網路。  

---

**Network三個基本元素**  

1.	Nodes/Hosts(節點/主機)：就是參與網路通訊的裝置，例如PC、Server。  
2.	Communication Link(溝通鏈)：裝置之間傳送資料的媒介，可以是有線(例如Ethernet Cable乙太網路線 / Fiber Optic光纖)或無線(例如Wi-Fi、Bluetooth、4G/5G)。  
3.	Protocol(協定)：通訊雙方共同遵守的規則，假設PC a傳給PC b，那問題來了：「要怎麼傳？資料長什麼格式？什麼時候可以傳？收到之後怎麼知道有沒有錯？」，這時就需要Protocol。<br><br>
   例如你跟我說「你好」，我會知道這是一句中文問候，但如果我們兩個完全不知道對方語言，就沒辦法有效溝通。  
   電腦也是如此，假設PC a傳Hello給PC b，b收到一堆0101010101，B要怎麼知道「哪些是資料？哪些是控制資訊？資料從誰來？要道給誰？有沒有遺失？要不要重新傳？」。  

---

**常見的Network Protocol**  

- HTTP
- TCP
- UDP
- IP
- DNS
- Ethernet

---

**每一個Protocol都負責不同的事情**  

網路不是只有一個Protocol，而是有很多個Protocol一起合作，假設今天開 ``` https://www.google.com ``` ，背後可以同時涉及DNS → IP → TCP → TLS → HTTP → Ethernet/Wi-Fi。  

這就是我們要「分層」的原因，如果所有事情都塞在一個Protocol裡，會變得非常難管理，所以我們把功能拆開：「Application → Transport → Network → Data Link → Physical」，每一層處理自己的工作。  

---

**Network的範圍其實非常大**  

從很小的PAN(Personal Area Network 個人區域網路)：例如手機 → 藍芽 → 耳機。  

LAN(Local Area Network 區域網路)：例如家庭、學校、公司辦公室。  

WAN(Wide Area Network 廣域網路)：例如台北 → ISP(網際網路服務供應商) → 台中。 
 <br>

**LAN與WAN不要只用距離來理解**  

LAN通常是「由單一組織或單一區域管理的區域網路」，例如學校校園網路、公司內部網路、家庭網路。  

WAN通常是「連接不同LAN或較大範圍網路的網路」，例如LAN → Router → WAN → Router → LAN。  

---

Internet：Network + Network + Network + Network = Internet，很重要一個概念就是Network of Networks，也就是由大量不同的網路互相連接而形成的全球性網路。  
<br>

**網路 ≠ Internet**  

假設你家有Phone跟Printer，即使你家的Internet斷線，這兩台裝置仍然可以互相通訊，Internet是非常大的互聯網路，而你家自己的LAN本身就是一個Network。  

---

**Internet Provider(ISP 網際網路服務供應商)**  

ISP提供讓你的網路可以連接到其他網路的服務，例如你的電腦 → 家用Router → ISP → Internet。  

---

**Network Communication的基本流程**  

假設PC A要送資料給B，PC A → Switch → Router → Internet → Router → Server B  

大致上會經過 Application Data → 建立傳輸資訊 → 加入IP資訊 → 加入Link Layer資訊 → 送出 → 經過各種Network Devices → Server B  

---

**Network Device重要角色**  

- Host(主機)：最終參與通訊的裝置，例如PC、Server、Phone。  
- Switch(交換器)：主要在LAN中轉送Frame(中文常翻為訊框或幀)
  ```text
    PC ─┐
        ├─ Switch
    PC ─┘
  ```
- Router(路由器)：連接不同Network，並根據Routing決定Packet往哪裡走。  
  ```LAN A → Router → LAN B。```
- Access Point(AP 存取點)：讓「無線」裝置接入網路，Laptop → AP → LAN。
