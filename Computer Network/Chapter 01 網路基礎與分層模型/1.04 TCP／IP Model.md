### TCP/IP Model  

---

**什麼是TCP/IP**  

不是單純指TCP + IP，而是一整套Internet Protocol Suite(網際網路協定套件)，裡面包含很多不同Protocol，例如Application：「HTTP、DNS、SMTP、FTP」、Transport：「TCP、UDP」，等等。  

---

**TCP/IP Model**  

最常見的是四層模型
| Layer |	名稱 | 對應OSI模型 |
|-------|-----|-------------|
| 4 |	Application |	Layer 7、6、5 |
| 3 |	Transport |	Layer 4 |
| 2 |	Internet |	Layer 3 |
| 1 |	Network Access |	Layer 2、1 |  

雖然合併了，但功能沒有消失，只是沒有被分為獨立一層。  
例如Layer 6的Encryption可以由Application Protocol / Sercurity Protocol處理。  

---

**Layer 4 Application Layer**  

是「提供網路服務給應用程式的地方」，包含我們最常接觸的網路協定HTTP、DNS、SMTP、FTP、SSH、DHCP。  

---

**Layer 3 Transport Layer**  

主要TCP、EDP，負責Process-to-Process / End-to-End Communication，我們上一節提到的Port也在這裡。  

---

**Layer 2 Internet Layer**  

主要負責Logical Addressing與Packet Forwarding，核心就是IP。  

---

**Layer 1 Network Access Layer**  

有些教材也叫Network Interface Layer，這裡處理Ethernet、Wi-Fi、MAC、Frame、Physical Transmission。  

---

**OSI vs TCP/IP**  

OSI比較適合理解功能如何分層。  

TCP/IP更接近Internet實際使用的Protocol Architecture。  

---

**TCP/IP不一定只有四層**  

有些教材也會把TCP/IP表示成五層  
| Layer |	名稱 |
|-------|------|
| 5 |	Application |
| 4 |	Transport |
| 3 |	Network |
| 2 |	Data Link |
| 1 |	Physical |  

把Network Access再拆成Data Link + Physical。
