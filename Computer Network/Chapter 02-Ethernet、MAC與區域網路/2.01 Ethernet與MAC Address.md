### Ethernet與MAC Address  

---

**Ethernet(乙太網路)是什麼**  

簡單來說它是一套「用於區域網路(LAN)的網路技術與通訊標準」，像我們平常看到的`PC → Ethernet Cable(網路線) → Switch`，就是非常典型的Ethernet。  

它包含了一整套規則，例如  
- Frame怎麼組成
- MAC Address怎麼使用
- 裝置怎麼在LAN中傳送資料
- Frame怎麼被接收與判斷
- 資料傳輸的格式

Ethernet主要屬於Layer 2，不過Ethernet的實體傳輸部分也會涉及Physical Layer。  

**Ethernet LAN長什麼樣**  

最基本可以想成  
```text
        Switch
       /   |   \
      /    |    \
    PC A  PC B  PC C
```  
如果PC A → PC B  
那PC A要怎麼知道「我要把資料交給哪一張網卡」，這時候就需要MAC Address。  

---

**MAC Address是什麼**  

MAC(Media Access Control 媒體存取控制)。  

MAC Address是Data Link Layer中用來識別網路介面的位址。例如  

`00:1A:2B:3C:4D:5E`，也可能看到`00-1A-2B-3C-4D-5E`，這兩種方式本質上都是同一種48-bis MAC Address。  <br>   

**為什麼是48bits**  

因為一個16位元 = 4bits，而一個MAC Address通常有12個Hex，所以12*4 = 48bits。  

---

**MAC Address的結構**  

傳統的48-bit MAC Address可以概念性分成部分  
```text 
┌──────────────────┬──────────────────┐
│     OUI          │ Device-specific  │
│    24 bits       │     24 bits      │
└──────────────────┴──────────────────┘
```

前24bits通常稱為OUI(Organizationally Unique Identifier 組織唯一識別符)，它用來識別「是哪個組織/廠商所管理的MAC Address範圍」。  

後面24bits的部分則由該組織用來區分不同的介面。  

---

**MAC Address不是永遠固定**  

現代作業系統與裝置可以「修改或偽裝(spoof)MAC Address」，另外現在手機、筆電等裝置也可能使用Randomized MAC Address(隨機MAC位址)，例如每次連接Wi-Fi時，不一定每次都對每個網路使用同一個MAC，這主要與Privacy有關。  

---

**MAC Address的三種重要類型**(下一節會詳細再介紹它們，先看看就好)  

**Unicast MAC**  

最常見「一對一」，例如  
```text
PC A
  │
  │ Frame
  ↓
PC B
```
Destination MAC：``00:11:22:33:44:55``  

代表「指定給某一個網路介面」  

---

**Broadcast MAC**  

用來將資料傳送給本機網路(Broadcast Domain)內所有裝置的特殊位址  

數值：所有位元皆1，就是`FF:FF:FF:FF:FF:FF`。  

但僅限於區域網路(LAN)內部。  

例如PC A想知道IP是`192.168.1.5`的PC B的MAC Address  

電腦A建立一個請求封包，內容寫著「誰有`192.168.1.5`的MAC位址？請回我」並且在Ethernet Header電腦A填入「電腦A的MAC Address(來源MAC)，與`FF:FF:FF:FF:FF:FF`(目的地MAC)」  
接著連接該switch上所有裝置(PC B、PC C等)都會收到這個Frame。  
最後PC C發現封包內詢問的IP不是自己，直接將封包丟棄。  
PC B發現詢問的IP是自己，於是記錄下PC A的MAC Address，並單獨回覆一個單播(Unicast)封包給PC A：「我就是`192.168.1.5`，我的MAC Address是xxx」。  

```text
  [電腦 A] (192.168.1.2)
     │
     │ 目的地: FF:FF:FF:FF:FF:FF (誰是 192.168.1.5?)
     ▼
┌──────────────┐
│ 網路交換器    │
└──────────────┘
   │   │   │
   │   │   └─► [印表機] (192.168.1.20) ──► 不理會，丟棄封包
   │   │
   │   └─────► [電腦 C] (192.168.1.10) ──► 不理會，丟棄封包
   │
   └─────────► [電腦 B] (192.168.1.5)  ──► 「是我！」➔ 回應給電腦 A
```

---

**Multicast MAC**  

一對多，但不是所有裝置，只有加入特定Multicast Group的裝置才需要接收。  

```text 
        Switch
       /  |  |  \
      A   B  C   D
          ↑  ↑
          └──┘
        Group
```

---

**MAC Address有兩個很重要的Bit**  

第一個Byte裡有兩個特別重要的bit  

**I/G Bit**：用來區分Individual / Unicast、Group / Multicast，也就是判斷這個MAC是單播還是群組位址。  

U/L Bit：用來區分Universally Administered、Locally Administered，也就是這個MAC是由廠商/全球分配機制管理，還是本地管理者設定。  

---

**一台電腦不一定只有一個MAC Address**  

假設一台筆電有接乙太網路卡跟Wi-Fi卡，它就可能有兩個不同的MAC Address，因為MAC Address跟Network Interface(網路介面)有關。  

---

**Virtual Machine(虛擬機)也可能有MAC**  

例如一台電腦裡有掛兩台虛擬機，它們也可以擁有自己的Virtual MAC Address。
