### Information Security
- **為什麼要學資安？**
  - 保護企業重要資訊
- 資安目標(Security Goals)
    - Confidentiality(機密性)
    - Integrity(完整性)
    - Availability(可用性)
- **如何保護？**
  - AAA
    - Authentication(身分驗證)
      - Something You Know.
      - Something You Have.
      - Something You Are.
    - Authorization(授權)
    - Accounting(稽核/記錄)
  - PoLP
  - Defense in Depth
- **如何管理？**
  - Policy
  - Awareness
  - Baseline
- **如何開發？**
  - Security by Design
  - Secure by Default
- **保護範圍**
  - Security
  - Privacy
  - Information Security
  - Cybersecurity
- **現代架構**
  - Zero Trust
