### Security by Design(安全設計)：安全不是最後加上去的，而是設計時就應該存在。  
在系統設計階段，就把資訊安全需求納入整個設計流程。安全不是外掛，而是系統本身的一部分。  

---

生活例子：  

汽車A做好後發現說，沒有做安全帶，這時才開始補做安全帶可以嗎？  
可以，但成本很高而且很麻煩。  
汽車B一開始設計圖就畫好「安全帶、ABS、ESP等等」，還沒開始做就把這些東西納入設計圖內，這就是Security by Design。  

---

Security by Design包含哪些事？  

1.	Authentication：要怎麼登入？密碼？Passkey？MFA？  
2.	Authorization：哪些人可以看、可以改？RBAC？ABAC？  
3.	Encryption：哪些資料要加密？AES、TLS？資料庫要不要加密？  
4.	Logging：哪些操作要留下Log？保留多久？ 
5.	Backup：資料怎麼備份？多久備份一次？  
6.	Input Validation：使用者輸入怎麼檢查？避免SQL Injection、XSS等等。  

---

**Security by Design就是指從設計開始，就思考如何保護CIA。** 

---

OWASP例子：  

做一個登入頁，Security by Design會先思考：需要MFA嗎？需要限制登入次數嗎？密碼要不要Hash？Session怎麼管理？Cookie要不要HttpOnly？等等。  

---

Security by Design的好處  

1.	降低修補成本：越晚發現問題，修正成本越高。  
2.	補洞比較少，減少錯誤率。  
3.	維護比較容易。  
4.	比較容易通過稽核。
