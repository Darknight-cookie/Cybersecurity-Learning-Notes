### ISMS常見迷思(Misconceptions)  

---

| 常見迷思 |	正確觀念 |
|---------|---------|
| ISMS = ISO 27001 |	ISO 27001是建立ISMS的標準 | 
| 有ISO就很安全 |	ISO建立制度，不保證零事故 |
| ISMS就是寫文件 |	文件只是制度的載體 |
| ISMS是IT的工作 |	全公司都要共同參與 |
| 設備越多越安全 |	制度 + 技術 + 人員才是完整 |
| 驗證過了就是完成 |	持續改善才是重點 |
| 風險必須為0 |	管理可接受風險 |
| PDCA做一次就好 |	PDAC是持續循環 |

---

**成熟的企業更在意的是：「我們是否真的依照ISMS持續改善？」**  

**資安一句話：Don’t build an ISMS for the certificate. Build it for the organization.  
(不要為了證書而建立ISMS，而是為了讓組織真正變得更安全。)**
