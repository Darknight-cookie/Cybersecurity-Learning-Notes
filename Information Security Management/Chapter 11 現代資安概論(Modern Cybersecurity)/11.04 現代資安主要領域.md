### 現代資安主要領域  

---

**一、 Network Security(網路安全)**  

最傳統也是最基礎的資安領域之一，核心目標：「保護網路、網路通訊以及網路上的資源」，它包含  
- Firewall
- IDS/IPS
- Network Segmentation
- VPN
- Network Monitoring
- Secure Protocols  
  
以上這些到技術篇會再細講。  

---

**二、 Endpoint Security(端點安全)**  

連接到企業環境的終端裝置，例如PC、Sever、Mobile，甚至某些IoT也會被視為Endpoint。  

Endpoint Security主要目的是「防止裝置被惡意程式或我擊者控制」，現代的Endpoint Security不只是裝防毒軟體，開始強調「偵測行為、分析活動、發現異常」，這也是之後會看到的EDR。  

---

**三、 Identity Security(身份安全)**  

核心是「你到底是誰」以及「你可以做什麼」，Zero Trust就是身份安全非常重要的基礎，它包含  
- IAM
- MFA
- SSO
- PAM
- Access Control
- Identity Governance

---

**四、 Cloud Security(雲端安全)**  

現在企業大量使用Cloud的IaaS、PaaS、SaaS，雲端安全主要保護雲端環境裡的系統、資料與服務。  

Cloud Security特別重要的一個問題：Misconfiguration(配置錯誤)，是指雲端上資料、伺服器或系統在設定時沒有符合最好做法，因而產生安全破口，例如忘記關閉權限、沒改預設密碼、把私人檔案設成公開。  

---

**五、Application Security(應用程式安全)**  

我們平常使用的Website、Mobile App、API本身都可能有漏洞，而Application Security的目標就是「在軟體生命週期中降低與處理安全風險」，常見的漏洞包含  
- SQL Injection
- XSS
- Path Traversal
- JWT
- Template Injection

---

**六、Data Security(資料安全)**  

企業真正要保護的東西通常還是Data，資料安全主要關心「資料整個生命週期的安全」，常見概念包含  
- Encryption(加密)
- Data Classification(資料分級)
- DLP
- Access Control
- Data Masking(資料遮罩)
- Backup

---

**七、Security Operations(安全營運)**  

可以理解成「每天持續做資安」，每天監控、改善，常見的包含  
- SOC
- SIEM
- EDR
- XDR
- Monitoring
- Alerting
- Incident Response
- Threat Hunting

---

**八、Threat Intelligence(威脅情報)**  

我們希望知道「外面現在有哪些威脅」，知情後可以提前調整防禦策略，不是坐在這邊等他們打過來。Threat Intelligence可以提供  
- Threat Actor(威脅者行為)
- Malware
- Campaign(攻擊活動)
- IOC(入侵指標)
- TTP(戰術、技術與程序)
- Vulnerability
- Attack Trend(攻擊趨勢)

---

**九、Incident Response(事件應變)**  

發生資安事件之後，組織如何處理與恢復，這在Chapter 7已經學過了。  

---

**十、DevSecOps(Dev + Security + Operations)**  

Security要融入Software Development Lifecycle(軟體開發生命週期)，不是等產品完成才檢查。我們之後技術會學  
- SAST
- DAST
- SCA
- Dependency Security
- CI/CD Security
- SBOM

---

**十一、AI Security(AI安全)**  

可以分為兩個方向  
1.	AI for Cybersecurity：用AI幫助資安，例如用AI做Log分析等
2.	Security for AI：保護AI系統本身，可能會面臨
   - Prompt Injection(指令注入)
   - Data Poisoning(數據投毒)
   - Model Theft(模型竊取)
   - Data Leakage(資料外洩)

---

現代不同的Security Domains共同形成完整防禦，資安要每個領域都做好，才是一個完整的防禦。  

第一章學過的概念Defense in Depth，不要只靠一層防禦，要建立多層防禦，即使一層被突破，還有下一層可以擋傷害。
