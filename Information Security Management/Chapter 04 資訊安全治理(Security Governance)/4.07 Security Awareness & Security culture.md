### Security Awareness & Security Culture(資安意識與資安文化)  

**Security Awareness：** 提升員工對資訊安全的認知與警覺，讓員工知道什麼是危險，並知道怎麼做。  

**Security Culture：** 資安已經成為公司的習慣與文化。例如今天所有員工看到可疑的Email，不用提醒就會自己回報。  

Awareness：知道、教育、認知、短期建立，是資安的起點。  
Culture：習慣、文化、行為、長期養成，是資安的目標。

延伸知識  

**常見的一個縮寫**   
SAT(資安意識教育訓練 Security Awareness Training)：  
很多企業每年都會要求員工完成SAT，內容可能包括：密碼安全、釣魚信辨識、個資保護、USB使用規範、AI工具使用規範等。  


最近因AI興起，越來越多公司把AI詐騙、Deepfake、Prompt Injection(指令注入攻擊)等新型威脅加入SAT的課程，所以Awareness也必須隨著攻擊手法持續更新。
