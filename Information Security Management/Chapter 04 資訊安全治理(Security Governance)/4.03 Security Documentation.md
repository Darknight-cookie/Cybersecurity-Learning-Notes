### Security Documentation(資訊安全文件 Policy、Standard、Procedure、Guideline (PSPG) )  

---

若今天董事會決定：所有重要系統都必須使用MFA。  
那這時IT會開始問：哪些算重要？Google Authenticator可以嗎？等問題。  
企業就發現「一句話」根本不夠，所以會慢慢建立一整套文件，就是今天的四位。  

---

**四者的關係：Policy → Standard → Procedure → Guideline，越往下越具體。**  

- **Policy(政策)：** 必須做什麼，通常回答What，例如：所有管理員帳號必須啟用MFA。  
- **Standard(標準)：** 要做到什麼標準，例如Policy規定「密碼必須安全」，請問要多安全？所以Standard就開始：至少12碼、大小寫、數字等。  
- **Procedure(程度)：** 一步一步怎麼做，例如新員工要開啟MFA，Procedure就會寫：1. 登入AD，2. 建立帳號，3. 綁定手機…，開始一步一步教。  
- **Guideline(建議)：** 提供建議，不一定要強制，例如建議使用「Microsoft Authenticator」。  

---

生活例子：  
學校規定「學生必須穿制服」(Policy)  
接著制服是「白色上衣、黑色褲子」(Standard)  
穿制服的流程「到合作社買、量尺吋、繳費」(Procedure)  
接著老師提醒「建議每天燙制服」(Guideline)。
